# Question Log

This page is where you record every question the onboarder could not answer. The onboarder cannot edit this file, so add each row yourself.

## How It Works

1. The onboarder says "That isn't in my notes" and names the owning title.
2. You add the question below and bring it to the end-of-day check-in.
3. The owner answers and stores the answer in Cairn (`second-brain.md`).
4. The Head of Sales adds the answer to the right file in `reference/`, so the next new hire never
   has to ask.
