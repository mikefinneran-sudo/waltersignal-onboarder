# Question Log

This page is where you record every question the onboarder could not answer. The onboarder cannot edit this file, so add each row yourself.

## How It Works

1. When the onboarder says "That isn't in my notes" and names the owning title, add your first row.
2. You add the question below and bring it to the end-of-day check-in.
3. The owner answers and stores the answer in Cairn (`second-brain.md`). Ask at the next check-in whether it is stored, and search Cairn for it.
4. The Head of Sales adds the answer to the right file in `reference/`. Read the file at the next check-in and mark the row done.
